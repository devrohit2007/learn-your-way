# Learn Your Way

> You don't have to learn it their way. Learn it your way.

Built for the **Suvidha AI Hackathon 2026**.

## The problem

Some people don't struggle to learn. They struggle with how information is presented. A concept that takes 10 reads in a textbook might click immediately when explained as an analogy, a diagram, or a step-by-step breakdown.

## The solution

Learn Your Way takes any learning material and explains it in four different ways:
- **Simple** — plain language, no jargon
- **Analogy** — a familiar real-world comparison
- **Visual** — a diagram or flow
- **Step-by-step** — sequential breakdown

If the first explanation doesn't land, the learner picks another style. The same concept, explained differently — until it clicks.

## Running locally

```bash
# No build tools needed. Just open index.html in a browser.
# Or serve with Python:
python3 -m http.server 8080
```

Then open `http://localhost:8080` in your browser.
