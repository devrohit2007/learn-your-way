You don't have to learn it their way. Learn it your way.

The person we built for

"I understand things when someone explains them to me. But the moment I open a textbook, I'm lost."

A student who can grasp concepts conversationally but struggles when the same ideas are presented as dense, technical written material. The knowledge isn't the barrier — the format is.

The barrier

Dense, jargon-heavy material locks out learners who think visually, narratively, or step-by-step. They are not less intelligent. They are being failed by a single presentation format that was never designed for how they learn.

What changes

The learner pastes any material and chooses how they want it explained. If it doesn't click, they hit "Explain it differently" and receive the same concept in a completely different format — until it lands.

What is fully built

4 explanation modes

Simple, Analogy, Visual diagram, Step-by-step — all AI-generated, all switchable mid-session.

Adaptive re-explanation

"Didn't get it?" buttons let the learner switch mode instantly without starting over.

Practice + Quiz

3 practice questions + 4 quiz questions. Wrong quiz answers link back to re-explanation.

3 languages

English, Hindi, Tamil — all explanations, practice, and quiz questions available in all three.

PDF + Image upload

Text PDFs extracted directly. Images processed by a vision model for OCR and diagram description.

Listen / TTS

Every explanation can be read aloud using the browser's Web Speech API — no extra service needed.

AI & tool disclosures

Tool / Model What it was used for
Claude (Anthropic) Coding assistant used throughout development to write, debug, and refine all project code
nvidia/nemotron-3-ultra-550b-a55b Powers all text explanations, practice questions, quiz generation, and key term extraction inside the app
meta/llama-3.2-11b-vision-instruct Vision model used to extract text and describe diagrams from uploaded images
pypdf (open source) Extracts text from uploaded PDF files on the backend
Web Speech API (browser built-in) Text-to-speech for the Listen feature — no external service

No datasets were used. All explanations are generated at runtime by the AI models above.
